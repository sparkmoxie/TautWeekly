Credential boundary

Runtime data is never source data.

Live configuration contains an SMTP credential and Tautulli API key, and may contain a Plex token. State, logs, previews, and backups may reveal recipients and server activity.

Read the hardening guide
  • Never commit live config or `.env`
  • Keep port 8787 private
  • Use application passwords
  • Rotate exposed credentials
