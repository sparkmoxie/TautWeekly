# TautWeekly for Plex v0.23.3

Released: 2026-08-27

## Consistent qualifying watches

Personal movie and TV cards, Movie Trending, Hot New Release, Top Genre, and
Binge Champion now share one completed-view rule: a history row qualifies when
Tautulli reports `watched_status=1` or completion reaches the configured
`WatchedPercent` threshold (85% by default). Active sessions remain excluded.
Partial playback continues to contribute only to personal total watch time.

Each grouped Tautulli history reference counts as one play. Separate qualifying
references, including rewatches, still count again and add their watch time.
Direct Play, Direct Stream, and transcode sessions follow the same rule.

## Refined weekly cards

- Personal TV rows retain the show title, poster, and show-level IMDb rating,
  then show only the number of qualifying unique episodes: `1 episode`,
  `2 episodes`, and so on. Per-show duration is no longer displayed.
- Movie Trending and Hot New Release rank qualified plays first, followed by
  unique viewers, qualified watch time, and their established recency tie-break.
- Hot New Release names the configured server when activity exists and uses
  `Freshly added!` when no new movie has qualifying activity.
- Binge Champion reports total qualifying plays before the nonzero movie and TV
  show counts. Top Genre uses qualifying movie history.
- Partial movie and episode sessions no longer make completed-view cards appear.

## Configuration compatibility

The obsolete `MinimumEpisodeSeconds` setup and Manager control has been removed.
Existing configuration files may retain the key safely; current builds ignore
it. No live configuration migration is required.

This is a statistics-correctness maintenance release. The v0.23.0 unified-
container Quickstart feature spotlight remains unchanged.
