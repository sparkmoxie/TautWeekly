# TautWeekly for Plex v0.28.2

Released: 2026-11-21

## Library selection and previews after switching Plex servers

Tautulli can retain inactive library records from another Plex server with the
same section IDs as your current libraries. In v0.28.0 and v0.28.1, Manager
could mark those libraries unavailable, and a preview could fail even when the
duplicate ID belonged to a library outside the newsletter.

Manager, setup verification, and the renderer now check the connected Plex
server's identity and look for a single active record of the expected library
type. Archived, deleted, and conflicting libraries stay unavailable. Before
releasing a preview or sending a newsletter, TautWeekly rechecks the libraries
used in that render.

On Unraid, update the container from the Docker tab and keep its existing
`/data` mapping. If you pinned an older image, edit the repository to
`ghcr.io/sparkmoxie/tautweekly:0.28.2` and apply. In Manager, open **Config**,
check **Repeat this Tautulli lookup**, click **Refresh Tautulli choices**,
and generate a local preview. Your saved selections and Tautulli history can
stay in place.
