# TautWeekly for Plex v0.20.6

v0.20.6 makes the main Manager header **Refresh** perform the same manual
stable-release check as Settings **Check now** after local status loads.

This prevents a newly published release from remaining hidden behind the
24-hour background freshness cache. The existing five-minute request limit,
failure backoff, and single active-check guard remain in place.

The recipient platform icon introduced in v0.20.5 is unchanged: generated
previews and test sends derive it from the selected user's actual report-window
Tautulli history, and omit it when no recognized platform is available.
