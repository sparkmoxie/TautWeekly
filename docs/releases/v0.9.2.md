# TautWeekly for Plex v0.9.2

v0.9.2 completes the provider-labelled rating fallback when direct Plex
metadata is unavailable and a controlled SendTest still omits movie Rotten
Tomatoes or show IMDb ratings.

## Diagnosis and correction

Tautulli documents `sub_media_type` as optional for `get_export_fields`, but
its current field-discovery implementation calls `.split()` on that value.
Omitting it can reject the discovery request before TautWeekly learns which
rating fields the installed exporter exposes.

v0.9.1 caught that error and claimed it would use standard rating fields, but
left `custom_fields` empty. That relied on each Tautulli version assigning the
same fields to metadata level 1. v0.9.2 instead:

- supplies the media type as a compatible, non-null subtype;
- always requests `rating`, `ratingImage`, `audienceRating`, and
  `audienceRatingImage` explicitly;
- applies the item exporter to show IMDb as well as movie RT and displays that
  recovered IMDb value on the TV release card;
- accepts valid minimal JSON instead of treating responses under 64 bytes as
  empty; and
- retains raw-JSON and resource-ZIP parsing from v0.9.1.

The behavior follows Tautulli's current
[`get_export_fields` implementation](https://github.com/Tautulli/Tautulli/blob/c7153deb6e3017b8dda46c8448fe548a61c5a47a/plexpy/webserve.py#L7102-L7134),
[`get_custom_fields` implementation](https://github.com/Tautulli/Tautulli/blob/c7153deb6e3017b8dda46c8448fe548a61c5a47a/plexpy/exporter.py#L2710-L2765),
and
[movie level-1 field map](https://github.com/Tautulli/Tautulli/blob/c7153deb6e3017b8dda46c8448fe548a61c5a47a/plexpy/exporter.py#L1419-L1434).

## SendTest regression

The virtual regression keeps direct Plex unavailable, refuses field discovery
without the compatibility subtype, refuses an item export without the four
provider-labelled fields, and returns low critic/audience plus show IMDb scores
as raw JSON. The show fixture is intentionally shorter than 64 bytes. The
regression now runs through SendTest and decodes the captured MIME message to
require all three scores and their provider icons in the delivered HTML on
every maintained renderer.

## Privacy and boundaries

The export remains at metadata level 1 with media information disabled. It
does not request file locations, stream details, recipient identity, viewing
history, or generated newsletter output. Provider-free numbers are not
assigned to Rotten Tomatoes or IMDb.

This correction does not make an unreachable direct Plex URL reachable.
TV/episode IMDb ratings still require an IMDb-labelled source, and missing
background or selected-logo resources remain omitted rather than guessed.
