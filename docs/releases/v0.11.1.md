# TautWeekly for Plex v0.11.1

v0.11.1 corrects Windows shortcut creation in the first one-click Setup
release. It also makes the Windows README and Quickstart consistently describe
Setup and the local Manager as the supported Windows workflow.

## Corrected Windows install, update, and migration

v0.11.0 guessed that the Desktop was at `%USERPROFILE%\Desktop`. That path may
not exist when Windows redirects the Desktop, including common OneDrive-managed
configurations. Setup could finish replacing the verified application files and
then report a `DirectoryNotFoundException` while saving the optional Desktop
shortcut.

v0.11.1 asks the Windows shell for the actual Programs and Desktop locations.
The Start Menu launcher is required and authoritative. Setup adds the Desktop
launcher when Windows exposes a usable Desktop; an unavailable optional Desktop
is recorded in the private installer log and no longer fails the installation.

## If v0.11.0 displayed the shortcut error

Do not uninstall TautWeekly or delete the selected application folder. The
shortcut error occurred after Setup had preserved or migrated the private data
and installed the application files.

1. Download `TautWeekly-Setup.exe` and `SHA256SUMS.txt` from v0.11.1.
2. Verify the EXE against `SHA256SUMS.txt`.
3. Run Setup and keep the exact same application folder selected.
4. Confirm **Update**. If the folder is still recognized as an older verified
   portable release, confirm **Migrate** instead.
5. Open **Open TautWeekly Manager** from the Start Menu. A Desktop launcher is
   also present when Windows makes that location available.
6. Confirm the Dashboard, Config status, generated previews, and owned schedule
   state before the next production send.

Configuration, credentials, library and user choices, delivery history,
generated previews, logs, backups, and Manager access state remain outside
release ownership and are preserved.

## Validation

The release gates cover Windows shell-folder resolution, redirected and missing
Desktops, optional shortcut failures, required Start Menu launchers, install,
verified update, portable migration, rollback, Manager boot, privacy-preserving
uninstall, release manifests, checksums, and reproducible archives.

The Setup executable is unsigned. Windows SmartScreen may identify it as an
unknown publisher; verify the downloaded file against `SHA256SUMS.txt`.
