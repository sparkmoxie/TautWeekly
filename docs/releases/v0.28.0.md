# TautWeekly for Plex v0.28.0

Released: 2026-11-11

## Tautulli 2.19 compatibility

Archived users remain visible for configuration but cannot receive newsletters,
test previews, or Manual Welcome messages. Unarchiving restores eligibility
subject to the existing active-user, address, exclusion, and library rules.
Older Tautulli 2.18 responses without archive fields remain supported.

Current additions and weekly statistics exclude archived or deleted libraries
and users. Saved library IDs remain intact; unavailable selections never turn
into an unrestricted newsletter. Exact active recipients can retain historical
watched evidence within their saved library scope. No global archived-history
switch is enabled.

Artwork requests keep the Plex item key alongside the image path. If Tautulli's
stricter image proxy rejects external artwork, TautWeekly can use the same
item's Plex artwork. It does not bypass upstream external-image restrictions.

## Credentials and validation

Tautulli API keys travel in `X-Api-Key` headers rather than request URLs.
Authenticated requests refuse redirects, including artwork and export downloads.
Keep `TautulliUrl` pointed directly at the reachable API endpoint.

The release retains the current movie/TV count wording, omitted zero categories,
and quiet-week Trending and Recent Releases behavior. Package, renderer, privacy,
installer, and container verification uses synthetic services and virtual
platforms; physical appliances and real inbox clients are outside that coverage.
