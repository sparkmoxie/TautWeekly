# TautWeekly for Plex v0.27.3

Released: 2026-10-29

## Package reliability and lower repeated work

This maintenance release updates all five packages and the shared Manager.

- Fix FreeBSD image-version expansion, repair its exact legacy failed-install default without changing custom image pins, and document repository-root local image builds. Native Linux refuses no-op/downgrade updates, avoids the shutdown-lock delay, verifies the installed Manager and fresh service/scheduler heartbeats, and restores its root-owned snapshot after failed upgrades.
- Keep dashboard status polling independent of rendering. Share bounded Windows Task Scheduler observations, show their observation time, pause hidden-tab polling, and avoid rewriting unchanged fields.
- Serve public Manager assets using build-time Brotli, gzip fallback, content fingerprints and encoding-specific validators. Private responses and application HTML retain `no-store`; no runtime compressor is added.
- Reuse exact artwork within each newsletter run and fetch fallback hero artwork only when needed. Record numeric HTML/MIME size evidence, stream MIME from its private pickup file, and query watched history only for displayed movie candidates. Unmatched candidates retain complete-history lookup and recipient/library isolation.
- Bound managed-service Manager and scheduler logs, preserve Windows console defaults, and retain current configuration, renderer logs and delivery-history policies.
- Use the shared minimal runtime and selected Manager architecture in Mac fallback images. Build versioned container candidates once, verify and boot-test their exact platform digests, and preserve the complete SBOM/provenance index during publication.

Synthetic checks measure transfer sizes, message buffers, artwork/history calls and retained log bytes. They are regression evidence rather than promises of page-load, delivery-time, inbox placement or email-client behavior. Image dimensions, animation frames and timing remain unchanged.

See [configuration and resource evidence](../CONFIGURATION.md), the [Linux update guide](../linux/README.md), and the [Mac package guide](../mac/README.md).
