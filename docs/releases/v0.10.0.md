# TautWeekly for Plex v0.10.0

![TautWeekly detailed popcorn TW logo](../../assets/branding/tautweekly-logo-256.png)

This release adopts the exact approved detailed popcorn `TW` raster artwork as
TautWeekly's global product and application identity. It supersedes every
earlier simplified or vector redraw without changing newsletter content.

## Platform/package identity

- The Windows, NAS/Docker, Unraid, GHCR, macOS, Linux, and FreeBSD README
  badges remain platform/package identity and were not replaced by the product
  mark.
- The GitHub Pages platform cards and Quickstarts now use the current detailed
  Windows 11 mark, Docker Ocean Blue symbol, QNAP standard-color wordmark,
  Unraid red-to-orange wordmark, full-color Tux, and official full-color
  FreeBSD logo instead of generic `WIN`, `NAS`, `LIN`, or `BSD` placeholders.
- The user-approved Apple source geometry is retained exactly in a documented
  TautWeekly-gold display derivative. This is the only requested exception to
  native platform colors; the untouched black source remains as provenance.
- Every durable platform source/copy has fixed SHA-256 evidence, explicit
  dimensions, preserved aspect ratio, and adjacent accessible platform text.
- Product icons remain on Unraid Community Apps and private preview surfaces
  because those locations identify the TautWeekly application rather than the
  host platform.

The current repository does not maintain a QNAP QPKG/App Center package,
Windows Setup/uninstaller/executable, macOS app bundle, Linux desktop entry, or
FreeBSD GUI package. Those unsupported surfaces were not invented. The Windows
ICO is present in the portable package so separately approved installer work
can consume it exactly.

## Newsletter boundary

No generated newsletter template, provider icon, animated mail-state asset, or
runtime branding setting changed. The product mark appears on the private
preview service landing page only, not inside generated newsletters.
