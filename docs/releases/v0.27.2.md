# TautWeekly for Plex v0.27.2

Released: 2026-10-27

## Preserve numeric recipient exclusions

Fixes [issue #195](https://github.com/sparkmoxie/TautWeekly/issues/195): Manager
previously discarded numeric `ExcludedUserIds` while preparing its form, so an
unrelated save could write an empty exclusion list. Numeric `IncludedLibraryIds`
were affected by the same conversion.

Valid unsigned decimal integer IDs now become exact strings before reaching the
browser. Numeric, quoted, and mixed ID lists keep their recipient and library
scope through an unrelated save, including large IDs. Manager's operation checks
and the last-lookup recipient count honor numeric exclusions before and after
saving. Malformed stored ID lists produce a visible validation error and block
saving instead of being silently emptied. Email exclusions remain text-only.

**Review existing exclusions after updating.** If an earlier save already cleared
the list, the update cannot reconstruct it. Recover the intended IDs from a
private timestamped `config.backup.*.json`, or reselect the excluded users, and
check the saved policy before production delivery. Normal saves still create a
private backup first.

The fix ships in the shared Manager across all five platform packages and the
unified amd64/arm64 container image. Synthetic smoke tests exercise Manager's
configuration save and operation refusal, plus production recipient exclusion
under the maintained Windows, NAS/Linux/FreeBSD, and Mac renderer payloads without
real email delivery. See [recipient configuration](../CONFIGURATION.md) for details.
