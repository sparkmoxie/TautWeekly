# TautWeekly for Plex v0.21.4

This maintenance update makes bundled animated email artwork smaller and
ensures existing installations actually receive the updated assets.

- All 32 GIFs: **21,435,442 -> 2,704,515 bytes (87.38% smaller)**.
- One synthetic SMTP fixture: **10,133,029 -> 1,401,881 bytes (86.17% smaller)**,
  including base64 overhead. Actual email savings depend on referenced artwork.
- GIFs use twice their largest email display size, then lossless compression.
  The resize is an explicitly authorized resolution change, not a claim of
  mathematically lossless resizing. All 1,809 frames, delays, loops, transparency,
  and first-frame fallback behavior are retained. All 29 PNGs are unchanged.
- No accepted layout, typography, icon placement, attachment selection, or
  fetched Plex/Tautulli artwork changes. No runtime optimization dependency.

## Existing installations and custom artwork

On the first startup after this update, Docker/Podman and native Linux replace
**all shipped persistent asset filenames**, including same-name custom GIFs
and PNGs, and refresh the browser-preview mirror. Custom-only filenames and
all unrelated runtime data remain intact; no asset directory is wiped.

A content-based bundle marker prevents repeat replacement on ordinary restarts.
Later bundle changes (or a missing marker) trigger another refresh; maintenance
updates with identical bundled bytes do not. Explicit `repair-assets` restores
all stock files. Windows Setup/updater already replace shipped assets during
updates and preserve custom-only filenames through their verified update path.

Back up any same-name custom artwork you want to reapply. See
[bundled asset behavior and measurements](../EMAIL-ASSETS.md) for details.

## Verification and baselines

Checks cover every animation frame against the resized reference, original PNG
bytes, all maintained mirrors, synthetic desktop/mobile previews, migration and
failure safety, Windows update/rollback, and real container boot/restart.
Required CI, privacy, package/checksum, installer, container and publication
gates remain in force; no real services or email delivery are used.

Source baselines: Windows 1.10.4, NAS/Docker 1.5.4, macOS 1.4.4, native Linux
1.3.4, FreeBSD/Podman 1.2.4. No configuration migration is required.
The v0.21.0 Quickstart feature spotlight remains unchanged.

`AGENTS.md` now requires automatic, verified lossless optimization of future
local assets before deployment unless an exception is explicitly authorized.
Classic Outlook is structurally tested, not natively certified; recipient
watched state requires retained Tautulli history. Windows executables remain
unsigned: verify packages against `SHA256SUMS.txt`.
