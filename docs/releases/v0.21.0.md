# TautWeekly for Plex v0.21.0

v0.21.0 adds a privacy-preserving **Top Genre This Week** footer and makes a
Trending week describe its movie and TV shelves consistently in the message,
inbox preview text, browser preview, and test email.

## Complementary hero and footer

| Hero | Movie shelf | TV shelf | Full-width footer |
| --- | --- | --- | --- |
| **Hot New Release** | New Releases | New Releases | **Trending This Week** |
| **Trending This Week**, new TV present | Recent Releases, up to four movies excluding the hero | New Releases, up to four series | **Top Genre This Week** |
| **Trending This Week**, no new TV | Recent Releases, up to four movies excluding the hero | Recent Releases, up to four series strictly newer than one month | **Top Genre This Week** |

Trending never appears in both the hero and footer. With new TV, the line above
the date and the email preheader read `0 NEW MOVIES • X TV TITLE(S)`. Without
new TV they read `1 TRENDING MOVIE • X RECENT MOVIE RELEASE(S)` when an
authentic movie hero is available.

## Top Genre algorithm and privacy

Top Genre uses only qualifying movie activity from the newsletter window and
configured included libraries. TautWeekly resolves each distinct movie once and
uses only the first genre returned by Plex metadata. Matching is
case-insensitive; `Science Fiction`, `Sci-fi`, `Sci Fi`, and `SciFi` share the
canonical **Science Fiction** label.

Genres rank deterministically by:

1. total qualified watch time;
2. unique qualifying movie count;
3. qualifying play count; and
4. normalized genre name, alphabetically.

The card presents only the aggregate duration and unique movie count, such as
`6h 56m watched across 2 movies`. It contains no viewer, winner, or recipient
identity. Missing metadata and movies without a genre are skipped. Action,
Comedy, Crime, Drama, Fantasy, Horror, Musical, Mystery, Romance, Science
Fiction, Thriller, and Western use validated local animations. An unsupported
winner—or a week with no usable genre—uses the existing neutral movie artwork,
so preview and CID email output cannot emit a broken image.

## Typography and delivery parity

Binge Champion's movie/TV breakdown now uses exactly the same supporting font
size, weight, line height, and color as the personal total-watch-time support in
both split and standalone layouts. The Top Genre duration line uses that same
style. Binge eligibility, anonymous non-winner treatment, gold winner treatment,
and Manual Welcome omission are unchanged.

Preview, PreviewAll, SendTest, SendTestAll, scheduled delivery, and confirmed
manual delivery share the same release payload, dynamic count/preheader, footer
selection, and MIME-linked local artwork.

## Maintained package baselines

- Windows 1.10.0
- NAS/Docker/Unraid 1.5.0
- macOS 1.4.0
- native Linux/systemd 1.3.0
- FreeBSD/Podman 1.2.0

All packages include the twelve genre animations and checksum/animation
validation. Linux and FreeBSD inherit the verified shared OCI renderer and asset
set from the NAS/Docker source.
