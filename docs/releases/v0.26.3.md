# TautWeekly for Plex v0.26.3

Released: 2026-10-02

## Schedule time presentation

The Manager Schedule configured window now displays times such as **Friday at
3:30 PM local Windows time**. Schedule confirmations use the same 12-hour
AM/PM presentation, including correct midnight and noon labels.

This is a display-only correction. Saved `ScheduleTime` values remain in
`HH:mm` format, and Windows and embedded scheduler timezone behavior is
unchanged. The interactive GUI preview includes the same fix.
