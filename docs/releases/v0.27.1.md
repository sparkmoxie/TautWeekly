# TautWeekly for Plex v0.27.1

Released: 2026-10-09

## Clearer Dashboard status

The Schedule card now puts the observed next-run date/time beneath Installed,
shown in your browser's timezone. A ready scheduler includes an eligible primary
recipient count from the last successful lookup, with its timestamp. Household
BCC copies are separate. Unknown or incomplete evidence stays unknown; config
changes invalidate the count and Refresh updates it. Delivery still refreshes and
checks the live recipient roster independently.

Hover or keyboard-focus the Manager badge for its version and release state using
the same downward tooltip animation as the lock and Tailscale controls. Click it
to open Application and package status. Latest requires a successful, aligned
stable-release comparison; checking, failures, mismatches, and unknown states are
shown explicitly.

## Package audit and build improvements

Mac fallback and native Linux packages reuse the same compiled amd64/arm64
Manager binaries, eliminating two repeated Go builds per candidate. Artifact
validation checks byte-for-byte equality. The unified Docker source context now
excludes local build output and private runtime/configuration files. CI path
classification covers every release-builder consumer and renderer/installer
artifact contracts.

All five platform packages, the unified multiarchitecture image, Windows
installer, and live GUI preview use this release. See the
[package audit](../PACKAGE-AUDIT.md) for scope, intentional duplication, checks,
and validation limits. The Quickstart feature spotlight remains on v0.27.0
Household copies (BCC).
