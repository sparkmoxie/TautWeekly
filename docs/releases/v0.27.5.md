# TautWeekly for Plex v0.27.5

Released: 2026-11-06

## Package setup, updates, and newsletter wording

- Manager shows pairing, password recovery, and update steps for the installed
  package. Windows describes administrator approval, and Docker and Podman
  installs point to the wrapper or deployment tool that manages them.
- Connection hints use addresses reachable from the service or container and
  preserve saved settings. Scheduler status shows when Windows Task Scheduler
  was last checked and labels browser-local time correctly.
- Manual Welcome and production send confirmations include eligible household
  copies. Newsletter and preview copy explain who can receive the personalized
  recap and what the anonymous Binge Champion summary shares. Verify and test
  send labels distinguish connection checks, test mail, and SMTP acceptance.
- The five archive READMEs have working links. The guides cover QNAP SSH
  forwarding, selecting a new Compose image while keeping the data mount,
  advancing a FreeBSD image pin, and native Linux rollback.

See the [platform Quickstarts](https://sparkmoxie.github.io/TautWeekly/#platforms)
and [PR #199](https://github.com/sparkmoxie/TautWeekly/pull/199).
