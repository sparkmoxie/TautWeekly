# TautWeekly for Plex v0.28.1

Released: 2026-11-11

## Weekly activity restored

Fix empty weekly recaps and lost movie rankings when Tautulli history responses
omit library IDs. TautWeekly now requests each available selected library
explicitly, retaining the matching query scope when a response has no library
field. Conflicting library identities are still rejected.

Personal recaps, Hot New Release rankings, Trending, Top Genre, and Binge
Champion use the restored weekly activity. Archived-user and library protections,
exact-recipient isolation, and saved library selections remain enforced. An
unavailable saved scope never expands into an unrestricted newsletter.

## Reporting window includes the run date

History queries include completed plays started on every selected reporting day,
including the run date. A window shown as November 5–11 includes November 11
through 23:59:59 and excludes November 4 and 12. Tautulli applies the calendar
date selection before grouping history, preserving grouped plays and its local
daylight-saving boundaries.

## Movie links removed

Remove the optional external movie-link control and its email, plain-text, and
preview output. Existing saved keys cannot restore the removed behavior. Rotten
Tomatoes and IMDb ratings retain their existing behavior.

## Compatibility and validation

The fixes apply to previews and delivery across the maintained packages. Current
movie/TV count wording, omitted zero categories, and quiet-week Trending and
Recent Releases behavior remain intact. Verification uses sanitized upstream-shaped
responses and virtual services; no live server access or real inbox delivery is
part of that coverage.
