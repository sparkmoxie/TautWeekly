# TautWeekly for Plex v0.23.2

Released: 2026-08-27

## Cache verification sequencing

**Validate, save, and verify** now treats the existing no-email PreviewAll
warm-up as a prerequisite when it can start. Deleted-item cache health shows
**Waiting** during that work instead of reporting a premature Warning. When
PreviewAll reaches any terminal state, Manager automatically runs the complete
local cache check and records the actual Passed, Warning, or Failed result.

The automatic check covers configuration, storage initialization, bounded
entry and byte limits, manifest and backup structure, local writability,
aggregate counts, expiry cleanup, and artwork integrity. The retained result
is shared by Dashboard Config status and Verify, including after a page refresh.

## Optional recheck and disabled state

**Check deleted-item cache** remains an optional recheck for later filesystem
or configuration changes. It is no longer a required second step after a
successful configuration workflow.

When cache storage is disabled, Verify offers **Enable Cache Storage**. The
action navigates to Config and smoothly focuses the deleted-item cache setting;
it does not toggle or save the setting. Waiting and completed health states now
use consistent badge, card, text, border, background, and glow transitions.

## Privacy and safety

PreviewAll and cache verification remain local and send no email, authenticate
to no SMTP server, and alter no schedule. The fixed-content writability probe
is removed after use. Manager exposes only aggregate health and counts-never
paths, titles, GUIDs, rating keys, hashes, artwork, viewing metrics, recipient
data, credentials, manifest contents, or cache contents.

See [Configuration](../CONFIGURATION.md#persistent-deleted-item-cache) and
[Troubleshooting](../TROUBLESHOOTING.md#deleted-item-still-has-no-poster-or-metadata)
for operation details and safe interpretation.

This is a maintenance UX release. The v0.23.0 unified-container Quickstart
feature spotlight remains unchanged.
