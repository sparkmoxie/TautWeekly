# TautWeekly for Plex v0.10.4

v0.10.4 refines personal recap ratings without changing how viewing activity
is grouped or how release-card episode ratings are selected.

## What changed

- Most-watched TV statistics remain consolidated by show and ranked by
  qualifying watch duration. They now display the exact show's IMDb score
  first, then its Rotten Tomatoes critic score, then its RT audience score.
- Movie statistics retain their existing RT-first and labelled-IMDb-fallback
  behavior.
- When no eligible movie or show score exists, the rating line is omitted. The
  recap no longer prints `Ratings unavailable` or `IMDb unavailable`.
- TV release cards are unchanged: their rows continue to use ratings tied to
  each exact episode rather than borrowing a show-level score.

## Validation and boundaries

Synthetic renderer coverage exercises IMDb priority, RT critic and audience
fallbacks, score-dependent RT artwork, aggregate show duration, and genuinely
unrated rows in every maintained renderer source. Package validation confirms
the shared NAS renderer is carried into native Linux and FreeBSD releases.

All lookups remain bound to the existing exact Plex/Tautulli item identifiers.
No title search, new external provider, schema change, configuration migration,
or new stored data is introduced. Tests and release assets contain no private
configuration, credentials, viewing history, recipient identity, logs,
upstream responses, or generated newsletters.

## Platform baselines

- Windows Portable 1.8.6
- NAS/Docker Portable 1.3.4
- macOS Portable 1.2.4

- FreeBSD Podman source baseline 1.1.6

## Upgrade

Use the matching v0.10.4 archive or pull
`ghcr.io/sparkmoxie/tautweekly:0.10.4`, recreate the container, run the
platform verifier, and regenerate PreviewAll. Existing configuration and state
remain compatible. Verify every download against `SHA256SUMS.txt`.
