# TautWeekly for Plex v0.12.4

v0.12.4 finishes the Windows acceptance fixes discovered after v0.12.3. It
releases Setup deterministically after installation, gives the running Manager
the approved product identity, and keeps preview and recipient selection inside
the Manager's existing authenticated interface.

## Let Setup exit before Manager starts

Windows Setup now dismisses its completion dialog, queues a hidden post-exit
handoff, and terminates. The handoff waits for that exact Setup process to exit
before starting the installed Manager and opening the browser. The downloaded
`TautWeekly-Setup.exe` is therefore no longer retained by a completed Setup
process and can be moved, deleted, or replaced by a future update.

The Windows installer lifecycle test exercises the real handoff boundary in an
isolated test installation. It waits for a marker written only after Setup has
exited, then moves the exact candidate EXE away and back to prove that no file
lock remains.

The installed Manager continues to use the compatibility-sensitive filename
`tautweekly-manager.exe`, but its Windows file description and product name are
now **TautWeekly for Plex** and its executable contains the approved popcorn/TW
application icon. That identity is used by Task Manager and other Windows shell
surfaces that read executable resources.

## Keep guided exclusions visible

The guided delivery roster now groups all configured exclusions first. A user
matched by an existing `ExcludedEmails` rule remains visibly checked and is
labelled **Excluded by existing config**. It stays protected from an ID-only
toggle because unchecking an ID cannot remove the underlying email rule.

Legacy matching remains server-side. The browser receives only the matching
user's already-sanitized display record and a Boolean match flag; no email
address is returned, cached, logged, or added to generated output.

All three Tautulli user controls now open from a click anywhere in the input.
The field accepts immediate typed filtering and retains the same styled,
bounded, scrollable option panel for mouse selection.

## Open preview-index links in place

The generated Index newsletter still provides one **Open preview** link per
scenario. Inside the Manager, those links are now intercepted and resolved
against the authenticated preview list. A click selects and displays the
associated preview in the existing pane and updates the highlighted item on the
left. It does not create a new window, load a nested frame, or expose a direct
filesystem path.

## Update from v0.12.3 or an older verified installation

1. Download `TautWeekly-Setup.exe` and `SHA256SUMS.txt` from this release.
2. Verify the EXE against `SHA256SUMS.txt`.
3. Run Setup and confirm **Update** for the preselected installer-owned folder.
4. Open **TautWeekly Manager** and run **Validate, save, and verify** once.

For an older portable/BAT installation, select that exact installation folder
in Setup and confirm **Migrate**. Configuration, credentials, email and ID
exclusions, history, previews, diagnostics, backups, password-lock state, and
an owned Windows Scheduled Task remain private and are preserved.

## Validation and limitations

Release gates cover Manager and installer unit tests and vetting, JavaScript
and accessibility checks, maintained Manager cross-builds, repository and
privacy validation, reproducible archives, package contracts, and isolated
Windows fresh-install/update/portable-migration/uninstall lifecycle testing.
Desktop and mobile browser QA used only fictional local fixtures and verified
all six Index links in place, searchable user controls, exclusion ordering,
responsive containment, and an error-free browser console.

The Setup executable remains unsigned. Windows SmartScreen may identify it as
an unknown publisher; verify the download against `SHA256SUMS.txt`.
