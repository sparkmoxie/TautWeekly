# TautWeekly for Plex v0.25.2

Released: 2026-09-01

## Binge Champion episode detail

Winner and non-winner Binge Champion cards keep the total play count and unique
movie/TV-show counts. When more than one qualifying episode was watched, the TV
summary now includes the cumulative episode total across every included show,
for example `25 plays • 1 movie • 2 TV shows: 7 episodes`. It does not repeat
the TV-show count as an episode count, and singular/plural labels remain
grammatical. HTML, plain text, all maintained renderers, and both GUI/email
preview fixtures use the same formatter and privacy boundary.

## Provider-neutral SMTP setup documentation

The central Markdown references now give a complete provider-neutral setup
sequence: collect the outbound submission settings, map every Manager field,
use STARTTLS rather than unsupported implicit-TLS port 465, distinguish
reachability verification from a real controlled send, and diagnose each
sanitized SMTP stage without exposing account data. The security reference also
covers sender authorization, credential handling, controlled first delivery,
and batch-stop behavior. Platform Quickstarts remain package-focused.

## Unraid Apps shortcut restored

The NAS / Docker landing-page card again links directly to the live TautWeekly
for Plex listing in Unraid Community Apps. The combined
NAS/Docker/QNAP/Unraid Quickstart remains the main installation and operating
guide; the restored shortcut opens the catalog entry for direct installation.

## Reliable Tautulli discovery

Manager setup and reconfiguration now use Tautulli's table-backed library and
user rosters when the primary Plex-backed discovery commands fail or return a
valid empty response. The parser also accepts the supported numeric, string,
and Boolean response variants seen across real Tautulli installations.

A failed refresh remains truthful: the request returns HTTP 502 and the
Choices step is Failed. When an exact-revision discovery cache is still valid,
its choices remain readable and selectable with an explicit retained marker
and timestamp. Older Tautulli, Plex, and SMTP connection checks are labeled as
separate retained evidence, so a historical Passed result no longer appears to
contradict a current library- or user-roster failure. Diagnostics expose only
allowlisted stage codes and sanitized guidance; raw provider output and private
server data are not returned to the browser.

## Funnel state survives ordinary updates

Windows Manager and installer updates no longer run destructive remote-access
cleanup before replacing the package. The password lock, verified public
hostname, publication proof, enabled preference, and fixed loopback Funnel
route remain retained through an ordinary update or rollback. Native Linux's
updated wrapper and installer now provide the same preservation for subsequent
updates.

Explicit **Disable**, stop, access reset/recovery, adapter revocation, and
uninstall operations still clean up the exact TautWeekly-owned route and
retained state. This release does not weaken those fail-closed lifecycle paths.

> **Native Linux v0.25.1 first-update note:** the already-installed v0.25.1
> wrapper performs its old cleanup before it downloads v0.25.2. That one update
> can therefore leave Funnel off and require deliberate re-enable/verification.
> Once v0.25.2 is installed, later ordinary updates preserve the verified state
> and route. Windows v0.25.1 updates are controlled by the downloaded candidate
> updater and receive the preservation fix immediately.

## Funnel status UI refinement

The Dashboard Funnel deep link now smooth-scrolls to the beginning of the full
Settings card below the sticky header. Its row is borderless, has a smoother
hover transition, and uses the same animated accessible tooltip treatment as
the access lock.

The Manager header now places a locally bundled Tailscale-light badge directly
after the lock:

| Funnel state | Badge appearance | Tooltip |
|---|---|---|
| Active | Source SVG bright/faded dots | Active |
| Publication pending | Source SVG bright/faded dots | Publication pending |
| Off, unsupported, not configured, disabled, blocked, failed, or any other non-active state | Uniform off dots | Exact sanitized state |

The icon geometry is bundled locally from Homarr Labs' Apache-2.0
`tailscale-light.svg`; the Manager does not hotlink the CDN at runtime. The
synchronized fictional GUI preview uses the same behavior.

## Package scope

The discovery and browser changes live in the shared embedded Manager shipped
by Windows, native Linux, Docker/NAS/QNAP/Synology/Unraid, macOS Docker, and
FreeBSD/Podman packages. Updater changes are limited to Windows and native
Linux, the two maintained paths that previously invoked cleanup during an
ordinary update.

The v0.25.0 Quickstart spotlight remains current because v0.25.2 repairs and
refines existing capabilities rather than introducing a new substantial
end-user feature.
