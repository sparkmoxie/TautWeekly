# TautWeekly for Plex v0.25.3

Released: 2026-09-01

## Windows Manager update relaunch

The v0.25.2 Windows update helper could replace the package successfully but
then fail to reopen a Manager that had been running when the update began. The
helper's automatic restart still called its private-data-directory resolver
after that resolver was accidentally removed. Its rollback path could restore
the previous application files but encountered the same restart failure,
leaving the local Manager unavailable until it was started or repaired
manually.

This hotfix restores the resolver and reads the private Manager directory from
the installed package metadata before relaunch. Ordinary update and rollback
continue to retain the password lock, enabled Funnel preference, verified
public hostname, publication proof, and fixed loopback route. A focused
installer lifecycle regression now starts the installed Manager, runs the real
staged update helper, verifies that a replacement process owns
127.0.0.1:8788, and confirms that the retained password and Funnel state are
readable after the automatic restart.

Users who already recovered v0.25.2 by rerunning Windows Setup do not need a
separate repair before installing v0.25.3.

## Exact Tailscale badge appearance

The header badge now uses the exact light SVG color and opacity model:

| Funnel state | Badge appearance |
|---|---|
| Active or publication pending | #f0f0f0 with the upstream four full-opacity and five 20%-opacity circles |
| Off, unsupported, not configured, disabled, blocked, failed, unavailable, or any other non-active state | All nine #f0f0f0 circles at 20% opacity |

The purple badge frame remains unchanged. Its animated tooltip continues to
report the exact sanitized Funnel state, and reduced-motion and forced-color
behavior remain available.

## Compact package badge labels

The top-right package badge now displays **Windows** for both installed Windows
Setup and Windows ZIP/fallback Managers. The macOS Docker Desktop package now
displays **macOS Docker**. Existing NAS/container, native Linux, and
FreeBSD/Podman identification is unchanged.

## Package scope

The badge refinements are in the shared Manager embedded in every maintained
package. The automatic-relaunch correction is specific to the native Windows
update helper. The v0.25.0 Quickstart spotlight remains current because this is
a corrective maintenance release rather than a new substantial capability.
