# TautWeekly for Plex v0.27.0

Released: 2026-10-07

## Household copies (BCC)

In **Config → Household copies (BCC)**, choose a source user and add individual
copy addresses, then save configuration. Each copy receives the source account's
exact personalized newsletter, including activity. Multiple households are supported.
Copy addresses are hidden; the primary recipient remains visible.

Use **View primary address** to inspect the selected user's native or fallback
address. The lookup is private, revision-checked, and cleared when leaving Config.
Native Tautulli email remains authoritative; a missing primary never becomes a
BCC-only delivery. Excluded or inactive sources do not send copies, and individual
copy addresses respect `ExcludedEmails`. TestEmail modes still send only to TestEmail.

One SMTP message serves each source account. A recipient-specific copy rejection
can leave the primary and other copies accepted; Manager reports those copy counts
and warnings separately. Provider-wide failures and unknown DATA acceptance still
stop safely, with no automatic resend of an accepted primary. Welcome state belongs
only to the source user and advances after final SMTP acceptance.

Copy-only saves do not regenerate previews, warm the cache, rediscover users, or
send email. Existing configurations default to no copies.

See the [configuration guide](../CONFIGURATION.md#household-copies-bcc) and
[recipient privacy](../SECURITY.md#recipient-privacy) for limits and details.
