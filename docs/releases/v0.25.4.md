# TautWeekly for Plex v0.25.4

Released: 2026-09-01

## Windows Funnel retention during update

Manager-driven Windows updates now stop only the exact installed Manager process
for package replacement and restart. They no longer invoke the ordinary
user-lifecycle shutdown command, whose deliberate safety behavior disables and
verifies the public Funnel before exiting. The candidate archive's verified
update helper performs this restart, so upgrading directly from v0.25.3 uses
the corrected path.

An active Funnel therefore retains its enabled preference, verified hostname,
publication proof, and fixed loopback route across an ordinary update or
rollback without another Windows approval. Explicit stop, access reset,
recovery, uninstall, and user-requested shutdown behavior remain unchanged and
continue to turn public access off deliberately.

## Header badge corrections

The update notification now uses the Manager blue for its icon, border, focus
state, glow, and animated halo. The Tailscale badge now places the approved
upstream light SVG paths directly in the status button so browser styling can
apply to every circle: Active and Publication pending use four full-opacity
and five 20%-opacity #f0f0f0 circles; every non-active state uses nine
20%-opacity #f0f0f0 circles. Existing animated, state-specific tooltips and
accessibility behavior are unchanged.

The top-right Windows package badge reads **Windows Manager**. The version
section continues to identify the edition as **Windows Manager**, and the
macOS Docker Desktop package retains the compact **macOS Docker** badge.

## Package scope

The badge corrections are in the shared Manager embedded in every maintained
package. Funnel retention is specific to the native Windows update helper.
The v0.25.0 Quickstart spotlight remains current because this is a corrective
maintenance release rather than a new substantial capability.
