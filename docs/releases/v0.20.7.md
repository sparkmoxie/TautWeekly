# TautWeekly for Plex v0.20.7

v0.20.7 keeps Preview and Send Test faithful to the selected recipient: the
six lifecycle layouts now use that user's real report-window statistics, and
zero activity remains a real empty state rather than generated viewing data.

Platform selection still prefers the recipient's most-played recognized
report-window platform with recency as the tie-breaker. If none is available,
TautWeekly asks Tautulli for that exact user's Last Platform and omits the icon
unless the result is recognized and recipient-matched. The locally embedded
21px glyphs now render white; no platform details are added to logs or Manager
history.
