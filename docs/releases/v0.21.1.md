# TautWeekly for Plex v0.21.1

v0.21.1 marks movies already watched by the newsletter recipient. This patch
preserves v0.21.0's dynamic Trending shelves and inbox preview text, Top Genre
footer, Binge Champion typography/privacy, and all lifecycle behavior.

## Exact watched-state rule

For each selected library scope, request all-time Tautulli `get_history` with
`grouping=1`, `include_activity=0`, `media_type=movie`, the exact recipient
`user_id`, and 1,000-row `start`/`length` pagination. No weekly `after` or
`before` filter is applied. Recheck every row's recipient ID, movie type, and
library scope. A row qualifies only when `watched_status=1` or
`percent_complete >= WatchedPercent` (default 85). Partial grades `0.25`,
`0.5`, and `0.75` are not watched by themselves.

Match only the movie's rating key or metadata GUID. Never match by title,
server popularity, the administrator's Plex watch state, or another user's
activity. The set is recipient-local and in-memory. Missing identity or a
failed historical lookup omits the supplementary marker and emits only a
generic warning; normal newsletter delivery remains available.

Tautulli must retain a qualifying historical row. A manual Plex watched mark,
or a watch before Tautulli's retained history, cannot be inferred from the
administrator's metadata token. See the complete
[configuration and privacy rule](../CONFIGURATION.md#recipient-movie-watched-markers).

## Placement and accessibility

- Desktop full-width movie heroes use the supplied 26×26 shield over the
  poster's upper-right corner: 7px inset and 5px raised. Outlook receives a
  fixed-coordinate VML group; other clients use a table overlay without CSS
  positioning. The unwatched poster keeps its original markup and spacing.
- Mobile heroes, release cards, personal movie recaps, and compact Trending
  titles use the supplied 20×20 circle immediately
  after the title, with uniform 6px left spacing and vertical centering.
- Both icons have `alt="Watched"` and `title="Watched"`. Plain text provides
  equivalent status. Unwatched movies add no markup or gap; TV titles remain
  unchanged. The dynamic inbox preheader is not polluted with icon text.
- Preview, PreviewAll, SendTest, SendTestAll, welcome, scheduled delivery, and
  confirmed manual production delivery share the same recipient state.

The original PNGs are unchanged. Both are 8-bit RGBA with transparent pixels,
validated PNG structure, and no added metadata. Exact bytes are packaged in
all maintained renderers, release-owned manifests, ZIP/TAR archives, checksums,
and container build contexts. Email resources are CID-linked only when used.

## Tautulli v2.18.0 compatibility

The [v2.18.0 release](https://github.com/Tautulli/Tautulli/releases/tag/v2.18.0)
moves history pagination into SQL without changing the consumed filters,
`recordsFiltered`, or movie identity/watch fields. Its
[tagged history implementation](https://github.com/Tautulli/Tautulli/blob/v2.18.0/plexpy/datafactory.py)
confirms graded watched status; the patch accepts only its definitive value.
The synthetic service identifies as v2.18.0 and covers omitted redundant
section IDs, more than one history page, and HTTP-400 invalid-metadata errors
through the existing exact-identity recovery path. No live Plex, Tautulli, or
SMTP endpoint is needed for these tests.

## Packages and upgrade

Source baselines are Windows 1.10.1, NAS/Docker 1.5.1, macOS 1.4.1, native Linux
1.3.1, and FreeBSD/Podman 1.2.1. No configuration migration is required.
Use the normal verified package/image update flow and retain private runtime
data. After updating, review previews and controlled TestEmail output before
re-enabling production delivery. Windows executables remain unsigned; verify
downloads against `SHA256SUMS.txt`.

The primary Quickstart feature spotlight intentionally remains v0.21.0.
