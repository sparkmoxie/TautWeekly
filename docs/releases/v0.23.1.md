# TautWeekly for Plex v0.23.1

Released: 2026-08-27

## Deleted-item cache visibility

Manager Dashboard Config status now includes a **Deleted-item cache** row.
The Verify page can run a local check for configuration, initialization,
manifest/backup health, write access, bounds, aggregate entry/artwork counts,
expiry, and artwork hashes. It contacts no external service and returns no
media identifiers or private file data.

Every maintained package also includes a `cache-status` command. It supports a
hidden exact-GUID prompt that reports only hit/miss/invalid and a non-sensitive
persistence marker that can prove a container or service restart retained the
same private data storage.

## Capture behavior

The cache remains future-facing and exact-ID only. Enabling it does not scan or
snapshot a Plex library. Preview, PreviewAll, SendTest, SendTestAll, scheduled
delivery, or confirmed manual delivery must select an item while live metadata,
a supported stable GUID, and a usable non-generic poster remain available.

When an enabled cache setting changes in Manager, **Validate, save, and verify**
now schedules the existing no-email PreviewAll workflow if one unambiguous
owner/administrator is available and no operation is active. This warms only
the qualifying items selected by the six previews. Manager reports an explicit
unseeded state when no qualifying capture has occurred.

## Runtime hardening

Cache initialization now performs a fixed-content write probe before reporting
availability. Manifest recovery state and one aggregate capture/skip/exact
hit/miss summary are logged without item identifiers. Existing schema, cache
contents, settings, retention, and storage paths remain compatible.

See [Configuration](../CONFIGURATION.md#persistent-deleted-item-cache) and
[Troubleshooting](../TROUBLESHOOTING.md#deleted-item-still-has-no-poster-or-metadata)
for platform commands and safe interpretation. Never post raw manifests,
artwork, configuration, tokens, GUID input, viewing history, recipients, raw
logs, generated output, or private paths.

This is a maintenance and diagnostics release. The v0.23.0 unified-container
Quickstart feature spotlight remains unchanged.
