# TautWeekly for Plex v0.27.6

Released: 2026-11-06

## Newsletter release counts

- Movie-only and TV-only weeks show the category with new additions. For
  example, a TV-only week can show **2 TV TITLES**.
- When nothing is new, the newsletter keeps any qualifying Trending movie and
  Recent Releases counts. When no count qualifies, the count line is hidden.
- The newsletter header, inbox preview, plain-text email, and public previews
  follow the same count rules.
