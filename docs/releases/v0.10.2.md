# TautWeekly for Plex v0.10.2

v0.10.2 refines TV release ratings after the v0.10.1 Plex provider-array
recovery was field-confirmed to restore movie Rotten Tomatoes scores.

## What changed

- TV release rows still prefer IMDb tied to the exact episode.
- When that episode has no IMDb score, TautWeekly now uses its exact Rotten
  Tomatoes critic score, then its audience score.
- The Rotten Tomatoes icon remains score-dependent: critic scores use the
  fresh/rotten tomato state and audience scores use the upright/spilled
  popcorn state.
- Series-level, movie, TMDB, TVDB, unknown-provider, and unlabelled numbers are
  never substituted beside an episode title.
- Movie behavior is unchanged: available RT critic/audience remains preferred,
  with labelled IMDb only as the final movie fallback.

## Evidence and privacy

Sanitized renderer and end-to-end PreviewAll/SendTest regressions cover both
provider shapes:

- an exact episode with IMDb and RT renders only IMDb;
- an exact episode with RT critic but no IMDb renders the RT critic percentage;
- flattened TMDB values and unrelated provider values remain absent;
- decoded test email HTML matches the browser preview contract on every
  maintained renderer source.

The lookup reuses the private authenticated Plex item request and bounded
Tautulli rating metadata path. It performs no third-party title search and
does not log or persist tokens, server responses, rating keys, viewing history,
recipient data, or generated newsletters.

## Upgrade

Use the matching v0.10.2 archive or pull
`ghcr.io/sparkmoxie/tautweekly:0.10.2`, recreate the container, run the
platform verifier, and regenerate PreviewAll. Existing configuration remains
compatible. Verify every download against the release's `SHA256SUMS.txt`.
