# TautWeekly for Plex v0.9.5

v0.9.5 restores the intended provider priority for movie and TV release
ratings across Windows, NAS/Docker, macOS, native Linux, and FreeBSD/Podman.

## Diagnosis and correction

v0.9.4 correctly learned to parse a provider-labelled score from either of
Tautulli's flattened rating field pairs, but it also treated any recognized
selected provider as completion. When a movie selected IMDb, TautWeekly could
stop before a later direct Plex, hosted Plex, public Plex watch-page, or bounded
Tautulli item-export path had a chance to supply Rotten Tomatoes critic or
audience values. The effect was most visible in a container that could reach
Tautulli but not Plex directly.

Movies now exhaust the supported RT sources before accepting a clearly labelled
IMDb fallback. If either RT critic or audience is available, only the available
RT value or values render. IMDb renders only when RT is wholly unavailable;
TMDB and TVDB are not substituted.

TV release rows again use only an IMDb value tied to the exact episode. A
selected TMDB/TVDB value no longer prevents the native Plex `Rating[]` or legacy
XML lookup for that episode, and neither a generic provider nor a show-level
score is displayed beside episode titles. Existing aggregated watched-show
statistics retain their dedicated show IMDb behavior.

## Preview and SendTest regression

The sanitized virtual NAS-like regression deliberately makes direct Plex
metadata return 404. Tautulli's normal movie metadata selects IMDb 6.6, while
its metadata-level-1 item export supplies RT critic 53% and audience 40%.
Preview and the decoded SendTest MIME message must contain both RT values and
must not contain the movie IMDb fallback. The TV card must contain the exact
episode IMDb 8.7 and must not display the available TMDB 7.4 show fallback.

The same collection and renderer assertions cover Windows, NAS/Docker, and
macOS sources. Hosted CI supplies PowerShell 7 execution for both container
renderers.

## Privacy and boundaries

No new external rating service or title search is introduced. The Tautulli
item export remains limited to `rating`, `ratingImage`, `audienceRating`, and
`audienceRatingImage` at metadata level 1 with media information disabled.
File locations, recipient identity, viewing history, generated newsletters,
credentials, and private infrastructure details are neither requested nor
persisted.

TautWeekly cannot invent an RT or exact-episode IMDb score that Plex and
Tautulli do not expose. In that case it uses the permitted labelled movie IMDb
fallback or leaves the episode unrated.
