Prepare Plex and Tautulli metadata before testing

  1. In Plex Web, confirm Edit > Advanced > Ratings Source for each included Plex Movie library.
  2. Run Manage Library > Refresh All Metadata for every included movie/TV library and wait for it to finish. A full refresh can take a long time and can update metadata or artwork.
  3. In Tautulli, open each same Library > Media Info tab, select Refresh media info, and wait. The current control is per library.

Complete this sequence after first install, after changing a Plex metadata agent or Ratings Source, or after a ratings/artwork recovery update when results may be stale. Routine TautWeekly updates do not require a full library refresh when current metadata already renders correctly.

First run on macOS

  1. From the extracted Mac package directory, retrieve the one-time pairing token.
  2. Open the Manager, create the administrator password, and complete Config.
  3. Select Save and verify, review all six authenticated previews, run TestEmail, then explicitly enable the schedule.
./tautweekly.sh manager-bootstrap
./tautweekly.sh open-manager

The token is returned only by the explicit bootstrap command and is never written to Docker logs. The terminal setup and verify commands remain expert/recovery fallbacks, not the normal setup path.

Update and recovery

Back up data/, verify and extract the newer stable Mac archive over this package without deleting .env or data/, then run ./tautweekly.sh update. Sign back in and verify version, health, Config, previews, and TestEmail in Manager. Use ./tautweekly.sh manager-reset-access only for credential recovery.
