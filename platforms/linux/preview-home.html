Use the authenticated Manager for administration

This loopback preview listener serves generated newsletter files only. Keep it private. Reach the Manager through the documented SSH tunnel at http://127.0.0.1:8788; never expose either listener directly to the internet.

ssh -L 8788:127.0.0.1:8788 YOUR_LINUX_ADMIN@YOUR_LINUX_HOST
sudo tautweekly manager-bootstrap

Finish setup in the Manager

  1. Pair with the one-time token and create a unique administrator password.
  2. Complete guided Config, then validate and save.
  3. Generate all six preview states and send only to TestEmail.
  4. Enable the independent weekly schedule only after acceptance passes.

Closing a browser does not stop the systemd service or change newsletter scheduling.

Prepare Plex and Tautulli metadata before testing

  1. In Plex Web, confirm Edit > Advanced > Ratings Source for each included Plex Movie library.
  2. Run Manage Library > Refresh All Metadata for every included movie/TV library and wait for it to finish.
  3. In Tautulli, open each same Library > Media Info tab, select Refresh media info, and wait. The current control is per library.

Complete this sequence after first install, after changing a Plex metadata agent or Ratings Source, or after a ratings/artwork recovery update when results may be stale. Routine TautWeekly updates do not require a full library refresh when current metadata already renders correctly.
