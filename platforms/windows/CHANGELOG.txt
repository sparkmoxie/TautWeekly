v1.8.0 Portable

- displays recovered show IMDb ratings on TV release cards
- verifies that SendTest delivers recovered RT and IMDb scores in the decoded MIME message
- fixes Tautulli single-item RT fallback requests and parses rating-only JSON exports
- limits that fallback to metadata level 1 with media information disabled
- adds a schema-versioned, bounded pre-deletion metadata and poster cache for exact stable GUIDs
- reuses cached presentation assets in PreviewAll, SendTest, and normal sends after future deletion
- defaults to 365 days, 1,000 items, and 256 MiB with atomic manifests and corruption recovery
- never caches tokens, API keys, recipients, viewing metrics, or generated newsletter output
- documents that v0.8.3 hosted recovery is best-effort and cannot repair assets already discarded
- preserves the dark-first email palette with Apple-compatible light/dark metadata, explicit longhand backgrounds, and table color fallbacks
- supplies Plex's required deleted-history title and episode-index match context, validates responses, and keeps missing artwork nonfatal
- retries empty modern Plex and legacy TMDB/TVDB exact matches through Plex's current provider POST contract
- recovers deleted Plex history through legacy TMDB/TVDB exact identifiers and reports unsupported or empty matches safely
- fixes deleted-history poster recovery on Unix-compatible packages by using a portable generic-poster probe
- restores IMDb ratings inside watched-TV personal statistics, including deleted-history shows
- restores missing movie RT and TV IMDb scores from Plex's exact tokenless public rating page
- recovers deleted Plex history posters and metadata from Tautulli's retained exact GUID
- treats sparse Tautulli hero metadata as optional during previews and test sends
- accepts selected-library recently-added rows when Plex omits the redundant section ID
- limits HOT NEW RELEASE to movies and falls back to Trending when no new movie exists
- lists up to four most-watched movies and TV shows, omitting an empty TV card
- replaces the packaged movie/TV stat GIFs while retaining CID asset behavior
- splits Binge Champion into watch duration plus nonzero unique movie/TV-show counts
- removes qualifying-play copy from Total Watched
