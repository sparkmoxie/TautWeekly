Manager online

The Manager is the setup source

Use this protected GUI for Config, verification, previews, controlled TestEmail delivery, schedule controls, status, and sanitized diagnostics. Terminal helpers are expert and recovery fallbacks.

There is no default password. If this browser has not been paired, retrieve the random one-time token only with the package's explicit manager-bootstrap command. The token is never printed to service or container logs.

Safe first run

  1. Open the Manager on the mapped or tunneled host URL.
  2. Enter the one-time token and create a unique administrator password.
  3. Complete Config, then choose Validate, save, and verify.
  4. Generate all six previews and send only to TestEmail.
  5. Enable the independent weekly schedule only after acceptance passes.

Closing the browser does not stop the container or scheduler. A graceful container stop closes Manager access first and allows an already-running newsletter delivery to drain within the host timeout.

Prepare Plex and Tautulli metadata before testing

  1. In Plex Web, confirm Edit > Advanced > Ratings Source for each included Plex Movie library.
  2. Run Manage Library > Refresh All Metadata for every included movie/TV library and wait for it to finish.
  3. In Tautulli, open each same Library > Media Info tab, select Refresh media info, and wait. The current control is per library.

Complete this sequence after first install, after changing a Plex metadata agent or Ratings Source, or after a ratings/artwork recovery update when results may be stale. Routine TautWeekly updates do not require a full library refresh when current metadata already renders correctly.

Update and recovery

Back up the persistent data volume before an image update. Use the host package's update controls, then sign back in and repeat Manager verification, previews, and TestEmail. Access recovery resets only Manager authentication and preserves /data/config.json, schedule state, output, history, and backups.
