Preview server online

This is a preview viewer, not an admin Web UI

Configuration and sending remain command-line operations so SMTP credentials and Tautulli access are never exposed through a browser control panel. Keep this port on a trusted network and do not publish it to the internet.

First run with Docker Compose

  1. From the extracted TautWeekly directory, run setup and verification.
  2. Generate the complete safe preview set.
  3. Return here and open the generated index.
./tautweekly.sh setup
./tautweekly.sh verify
./tautweekly.sh preview-all

First run from an Unraid container Console

pwsh -NoLogo -NoProfile -File /opt/tautweekly/Setup-First.ps1
pwsh -NoLogo -NoProfile -File /opt/tautweekly/Verify-Setup.ps1
/opt/tautweekly/bin/run-mode.sh PreviewAll

The required persistent configuration path is /data/config.json. Automatic weekly delivery stays disabled until you explicitly enable it after preview and TestEmail review.
