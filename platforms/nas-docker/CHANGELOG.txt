TAUTWEEKLY FOR PLEX NAS PORTABLE CHANGELOG
=================================

v1.2.0 Portable
---------------
- renders recognized selected IMDb, TMDB, and TVDB ratings from either Tautulli rating field pair
- makes Tautulli field discovery compatible and explicitly requests provider-labelled rating fields
- accepts valid minimal rating-only JSON exports instead of rejecting responses under 64 bytes
- displays recovered show IMDb ratings on TV release cards
- verifies that SendTest delivers recovered RT and IMDb scores in the decoded MIME message
- fixes Tautulli single-item RT fallback requests and parses rating-only JSON exports
- limits that fallback to metadata level 1 with media information disabled
- adds a schema-versioned, bounded pre-deletion metadata and poster cache under persistent data
- reuses cached presentation assets in PreviewAll, SendTest, and normal sends after future deletion
- defaults to 365 days, 1,000 items, and 256 MiB with atomic manifests and corruption recovery
- never caches tokens, API keys, recipients, viewing metrics, or generated newsletter output
- documents that v0.8.3 hosted recovery is best-effort and cannot repair assets already discarded
- preserves the dark-first email palette with Apple-compatible light/dark metadata, explicit longhand backgrounds, and table color fallbacks
- supplies Plex's required deleted-history title and episode-index match context, validates responses, and keeps missing artwork nonfatal
- retries empty modern Plex and legacy TMDB/TVDB exact matches through Plex's current provider POST contract
- recovers deleted Plex history through legacy TMDB/TVDB exact identifiers and reports unsupported or empty matches safely
- fixes deleted-history poster recovery on Unix by using a portable generic-poster probe
- restores IMDb ratings inside watched-TV personal statistics, including deleted-history shows
- restores missing movie RT and TV IMDb scores from Plex's exact tokenless public rating page
- recovers deleted Plex history posters and metadata from Tautulli's retained exact GUID
- honors PUID/PGID for newsletter commands started from a root container Console or exec session
- treats sparse Tautulli hero metadata as optional during previews and test sends
- accepts selected-library recently-added rows when Plex omits the redundant section ID
- limits HOT NEW RELEASE to movies and falls back to Trending when no new movie exists
- lists up to four most-watched movies and TV shows, omitting an empty TV card
- replaces the packaged movie/TV stat GIFs while retaining CID asset behavior
- splits Binge Champion into watch duration plus nonzero unique movie/TV-show counts
- removes qualifying-play copy from Total Watched
- separates stable image checks from apply actions on Compose and QNAP hosts
- blocks busy updates, verifies health/version, and rolls back the prior image
- documents Unraid-native notification/application without an in-container updater
- distinguishes host-side ./tautweekly.sh commands from Unraid Console commands
- prints valid container-native follow-up commands after setup and verification
- resolves the configured IANA timezone explicitly for every schedule decision
- refuses invalid timezones instead of silently sending on UTC
- reports the active scheduler timezone, local time, and UTC offset from its heartbeat
- adds setup and standalone global movie/TV library selection
- scopes releases, quiet mode, Trending, Binge Champion, and personal statistics upstream
- keeps container liveness healthy during long scheduled deliveries
- reports exact preview/supervisor health failures and treats missing artwork as repairable
- loads the exclusion roster from get_user_names and get_users in two bulk calls
- falls back to the bulk roster when Tautulli rejects a single-user lookup
- adds interactive stable-ID user exclusions to primary setup
- adds ./tautweekly.sh exclude-users for later recipient-policy updates
- preserves existing user-ID and email exclusions when setup is intentionally rebuilt
- ranks Binge Champion by qualifying watch time with total plays as the tie-breaker
- shares anonymous watch duration and nonzero unique movie/TV-show counts; only the winner sees gold
- treats missing Tautulli episode rating fields as optional during PreviewAll
- serves first-run setup guidance at the preview root before previews exist
- verifies and monitors the preview listener so bind/process failures are visible
- clarifies that port 8787 is a read-only viewer and /data/config.json is required
