TAUTWEEKLY FOR PLEX NAS PORTABLE CHANGELOG
=================================

v1.7.0 Portable
---------------
- adds password-gated public Tailscale Funnel for Docker, QNAP, Synology, Unraid, and compatible NAS surfaces
- replaces the private Serve sidecar with an isolated official userspace runtime and exact fixed-target lifecycle adapter
- keeps Manager non-root with no Docker socket, host executable, TUN device, network privilege, auth key, token, or arbitrary CLI input

---------------

- preserves /data, PUID/PGID/UMASK, health, scheduling, graceful stop, hardening, and host-owned updates

v1.5.4 Portable

- leaves PNG artwork, dynamic media, configuration, private data, and the accepted email layout unchanged

v1.5.3 Portable
---------------

v1.4.0 Portable
